# 🌿 WellNest - Personal Wellness Companion

WellNest is a mobile wellness application developed using Kotlin and Android Studio to help users build healthy daily habits, monitor emotional well-being, and maintain hydration through reminders and interactive wellness features.

## 📱 Overview

WellNest provides an all-in-one platform for personal wellness management by combining habit tracking, mood monitoring, hydration reminders, and progress visualization within a clean and user-friendly mobile application.

The application follows modern Android development practices and incorporates data persistence, graphical analytics, notifications, and home-screen widgets to improve the overall user experience.

---

## ✨ Key Features

### 📝 Daily Habit Tracker

* Add, edit, and delete daily habits
* Track habit completion progress
* Persistent data storage using SharedPreferences
* Daily progress monitoring

### 😊 Mood Journal

* Record daily moods using emoji-based selections
* Store mood entries with date and time
* Calendar-based mood history view
* Detailed mood logs

### 📊 Mood Trend Analytics

* Visualize emotional trends using charts
* Weekly mood analysis
* Implemented using MPAndroidChart

### 💧 Hydration Tracker

* Track daily water intake
* Monitor hydration progress
* Reset daily hydration records

### ⏰ Hydration Reminders

* Reminder notifications using AlarmManager
* User-configurable reminder times
* Encourages healthy hydration habits

### 🏠 Home Dashboard

* Daily wellness overview
* Motivational quotes
* Habit completion summary
* Hydration status
* Latest mood updates

### 📲 Home Screen Widget

* Displays daily habit progress
* Quick access to application features
* Real-time progress visibility

### 👤 User Profile

* Personal wellness profile management
* Wellness statistics
* Mood trend visualization
* Notes management
